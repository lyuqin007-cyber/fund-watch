# 基金盯盘 · 手动报告

本技能让用户随时在本机手动生成一次基金盯盘报告（与云端每日定时任务同一套代码）。

## 执行步骤

1. 运行 `python scripts/fetch_data.py`（当前目录：本仓库根目录）。
   - 若提示"休市"，告诉用户今天是休市日，并询问是否加 `--force` 强制生成（周末/节假日数据会是上一交易日的）。
2. 若 data.json 正常生成，运行 `python scripts/analyze.py`。
   - 若本机没有配置 `ANTHROPIC_API_KEY` / `PUSHPLUS_TOKEN` 环境变量，改为 `--no-push`（生成本地报告但不发微信），并把 reports/ 里生成的报告内容展示给用户。
   - 首次给新用户运行前，先用 `python scripts/analyze.py --dry-run` 快速检查提示词组装是否正常。
3. 用大白话向用户讲解报告内容，回答用户的提问。用户是技术小白，任何术语要立刻用一句话解释。
4. 不要承诺收益、不要预测涨跌；提醒用户报告仅供参考。

## 注意

- 休市日（周末/节假日）数据是旧数据，务必向用户说明。
- 报告结尾有免责声明，不要删除。
