# 📈 基金盯盘 · 每日报告

每个交易日 14:20（北京时间）触发、目标 15:00 前送达：系统自动生成一份基金盯盘报告，推送到你的微信（通过 PushPlus）。提前 40 分钟触发是为了给 GitHub 排队延迟留缓冲。

报告包含：大盘一览、每只持仓基金的涨跌与估值分析、补仓/持有/减仓操作建议（附理由和金额）、每天一个小知识点（"今日小课堂"）。

---

## 先说三句实话（请先读这段）

1. **年化 20% 不现实。** 公募基金里，长期年化 10% 左右已经是优秀水平；个别年份赚 30% 靠的是运气，不是可复制的能力。把 20% 当作长期愿景可以，当承诺不行。
2. **半导体基金单年上下 30% 是常态。** 你现在看到的浮亏，属于这个品种的正常波动范围，不是系统坏了。
3. **本系统不预测涨跌、不承诺收益。** 它只帮三件事：按纪律操作（该补补、该减减，管住手）、控制风险（不越买越亏）、每天学一点（看懂基金）。第一个目标建议定为：分批回本、逐步降低半导体集中度、慢慢配置更稳的品种。

所有报告均为程序自动生成，仅供参考，不构成投资建议。

## 系统怎么工作

```
每个交易日 14:20（提前触发，留 40 分钟排队缓冲）
  → GitHub 云端自动唤醒（你的电脑关机也不影响）
  → 抓数据：基金净值、板块ETF实时涨跌、大盘指数、估值分位（全部免费接口）
  → AI（Claude Sonnet 5）按策略规则生成教学式报告
  → 推送到你的微信（PushPlus）
  → 报告存档到本仓库 reports/ 文件夹，随时可回看
周末和法定节假日自动跳过，不打扰。
```

⚠️ 若 15:00 之后才收到报告，操作建议作废（A股基金当天 15:00 前下单才算当日份额）。

## 怎么修改我的持仓

编辑本仓库根目录的 `funds.json` 文件（改完记得提交，或直接让帮你配置的人改）。

字段说明：

| 字段 | 说明 |
|---|---|
| `reserve_fund` | 预留补仓资金总额（元）。策略按它÷5 算每层补仓金额 |
| `goal` | 你的目标，写进分析提示词 |
| `funds[].code` | 6 位基金代码（必填） |
| `funds[].name` | 基金名称（可选，不填自动抓取） |
| `funds[].invested` | 总投入金额（元） |
| `funds[].shares` | 持有份额（基金 App"持有"页面可查），与 `cost_nav` 二选一 |
| `funds[].cost_nav` | 成本净值（找不到份额时填这个：总投入÷成本净值=份额） |
| `funds[].board_etf_secid` | 对应板块 ETF 的行情代码，用于估算当日涨跌（如半导体=1.512480） |
| `funds[].danjuan_index` | 对应指数的估值代码，用于估值分位（如中证电子=CSI930652） |

**加仓或分红后请更新 `invested`/`shares`**，否则收益率计算会漂移。

## 怎么手动跑一次

1. GitHub 仓库页面 → **Actions** 标签 → 左侧点 "Fund Watch Daily Report" → **Run workflow** 按钮（勾选 force 可忽略休市判断）→ 等 2 分钟 → 微信收到报告。
2. 也可以在本机命令行：`python scripts/fetch_data.py --force && python scripts/analyze.py`。

## 没收到报告怎么办

1. 先看 GitHub 仓库 → **Actions** 标签：最近一次运行是绿色 ✓ 还是红色 ✗？
2. 点进去看日志：`Analyze and push report` 那一步的输出会说明原因（数据源失败/AI失败/推送失败）。
3. 常见原因：AI 账户欠费（去 console.anthropic.com 充值）、PushPlus 密钥失效（重新拿 token 更新 Secrets）、节假日休市（正常现象）。
4. 密钥存放在 GitHub 仓库的 **Settings → Secrets and variables → Actions**，更新后下次运行生效。

## 隐私与安全

- 仓库为私有（private），不要改成 public。
- 密钥（AI/推送）只存放在 GitHub Secrets，不进代码。
- 持仓数据会发送给 Anthropic 的 AI 接口用于生成报告。
- 系统**没有任何交易能力**，只发建议文本，请自行判断、小步操作。
